# LIBS - Popular Third-Party Libraries

Essential libraries for building production Go applications.

## CLI & Configuration

- **github.com/spf13/cobra** — Command-line application framework
- **github.com/spf13/viper** — Configuration management (YAML, TOML, JSON)
- **github.com/urfave/cli** — Simple CLI builder alternative

## Logging

- **go.uber.org/zap** — Structured, high-performance logging
- **gopkg.in/natefinch/lumberjack.v2** — Log file rotation

## Data & Encoding

- **encoding/json** — Native JSON support
- **github.com/golang/protobuf** — Protocol Buffers serialization
- **gopkg.in/yaml.v2** — YAML parsing

## Networking & Communication

- **github.com/vardius/message-bus** — Pub/Sub event bus
- **github.com/vishvananda/netlink** — Linux netlink interface

## Database & Cache

- **github.com/redis/go-redis/v9** — Redis client
- **github.com/lib/pq** — PostgreSQL driver
- **gorm.io/gorm** — ORM for databases
- **github.com/go-sql-driver/mysql** — MySQL driver

## Validation

- **github.com/go-playground/validator** — Struct validation

## Dependency Injection

- **go.uber.org/dig** — Constructor injection
- **github.com/google/wire** — Code generation-based DI

## State Machines

- **github.com/looplab/fsm** — Finite state machine
- **github.com/qmuntal/stateless** — Stateless FSM implementation

## Environment

- **github.com/joho/godotenv** — Load .env files

## Date & Time

- **github.com/golang-module/carbon** — Enhanced date/time utilities
